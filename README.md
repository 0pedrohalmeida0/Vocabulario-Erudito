## 🇺🇸 English Version

Vocabulário Erudito is a web application and PWA (Progressive Web App) designed to aid in daily vocabulary enrichment. The system allows users to focus their studies across different languages (High Proficiency Portuguese, Advanced English, and German), delivering definitions and practical examples stored in the database.

The project's key differentiator is its ability to be installed on a desktop or mobile device as a native app, featuring automated push notifications directly on the user's screen.

### Live Demo
The project has been successfully deployed to the cloud and can be tested directly via your browser or installed on your device through the link below:
🔗 **Access the application:** [vocabularioerudito.pythonanywhere.com](https://vocabularioerudito.pythonanywhere.com/)

### Technologies Used
* **Python & Django:** Back-end architecture, database management, dynamic term filtering, and template rendering.
* **JavaScript (ES6):** Front-end logic responsible for asynchronous *Service Worker* registration and control of the *Web Notifications API*.
* **PWA (Progressive Web App):** Integration of `manifest.json` and `sw.js` to enable offline support, static file caching, and installability.
* **Web Notifications API:** An automated mechanism that identifies the "word of the day" sent by Django and triggers a native system notification on the user's device.
* **CSS3:** Responsive and minimalist interface utilizing dynamic gradients and typography optimized for readability (*Inter* and *Playfair Display*).
* **Hosting:** Cloud production deployment powered by *PythonAnywhere*.

## 🇧🇷 Versão em Português

O Vocabulário Erudito é uma aplicação web e PWA (Progressive Web App) desenvolvida para auxiliar no enriquecimento vocabular diário. O sistema permite ao usuário focar seus estudos em diferentes idiomas (Português Erudito, Inglês Avançado e Alemão), trazendo definições e exemplos práticos armazenados no banco de dados.

O grande diferencial do projeto é a sua capacidade de ser instalado no computador ou celular como um aplicativo nativo, contando com automação de notificações na tela do usuário.

### Tecnologias Utilizadas
* **Python & Django:** Arquitetura do back-end, gerenciamento do banco de dados, filtragem dinâmica de termos e renderização de templates.
* **JavaScript (ES6):** Lógica de front-end responsável pelo registro assíncrono do *Service Worker* e controle da *Web Notifications API*.
* **PWA (Progressive Web App):** Integração de `manifest.json` e `sw.js` para suporte offline, cache de arquivos estáticos e instalabilidade.
* **Web Notifications API:** Mecanismo automático que identifica a palavra do dia enviada pelo Django e dispara uma notificação nativa no sistema do usuário.
* **CSS3:** Interface responsiva e minimalista, utilizando gradientes dinâmicos e tipografia otimizada para leitura (*Inter* e *Playfair Display*).
* **Hospedagem:** Deploy em ambiente de produção na nuvem através do *PythonAnywhere*.
